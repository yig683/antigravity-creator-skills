Gelişmiş: Chrome oturumu / OAuth

Chrome, güvenlik gereği çerezleri şifrelediği için dışarıdan otomatik okunamaz. Çıkış sonrası açılan pencereden yeni hesabına girebilir veya Chrome’da açık hesabı token ile anında bağlayabilirsin:

soundcloud.com/you/apps üzerinden aldığın OAuth bilgilerini girebilirsin.
